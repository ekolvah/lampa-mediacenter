# lampa-mediacenter — агентный workflow

Рабочие инструменты и правила для обслуживания домашнего медиацентра
(Android-приставка + Lampa + TorrServer + VLC) силами кодового агента.

Репозиторий содержит **только инструментарий и методологию**. Конфигурация
реального устройства, снапшоты LocalStorage/LevelDB и скриншоты сюда не
попадают: в дампах Lampa лежат токен и email привязанного CUB-аккаунта.
Это зафиксировано в [.gitignore](.gitignore) — правила запрещают `snapshots/`,
`settings.xml`, `*.ldb`, `leveldb/` и любые изображения.

## Текущая работа

Открытые задачи — во вкладке Issues. Все они выросли из замера в
`docs/token-efficiency-analysis.md`: одна шестичасовая сессия стоила **59.3M
входных токенов** при 358K выходных, и главный драйвер — не объём отдельных
ответов, а **число обращений к модели** (575 на 41 реплику пользователя).

## Конвенции

- Любая правка конфигурации устройства — только после снапшота, одно изменение
  за раз, проверка на реальном сценарии после каждого.
- Прямая правка LevelDB запрещена: формат бинарный, облачная синхронизация
  всё равно перетрёт локальное изменение. Штатный путь — `Lampa.Storage` через `cdp.py`.
- Секреты устройства (токены, email аккаунта, содержимое дампов) не покидают
  локальную машину.
