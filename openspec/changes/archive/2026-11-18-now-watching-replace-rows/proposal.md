## Why

Доработка по ревью PR #69 (tracking issue #68), решение пользователя от 2026-11-18. Пользователь
сверил ряды новинок на TV. По итогам он решил:

- старые карточки в рядах «Сейчас смотрят фильмы/сериалы» не нужны;
- нужен доступ к **полному** списку новинок, кнопка «Ещё» для этого подходит;
- менять логику показа самих штатных рядов, а не ставить рядом свои;
- непроверенные карточки показывать, но без приписки « · не проверено: N» в заголовке.

Замер на приставке (`KP.list` по всем страницам, 2026-11-18): в обеих коллекциях по 35 страниц
по 20 карточек. Карточек нужного года на страницах 1–5: фильмов 73 из ~270, сериалов 47 из ~200.
Ряд из первых пяти страниц даёт около четверти новинок. Значит, полный список должен идти по всем
страницам.

## What Changes

- Штатные ряды «Сейчас смотрят фильмы» и «Сейчас смотрят сериалы» на Главной KP показывают только
  новинки со страниц 1–5 коллекции. Место, заголовок и кнопка «Ещё» у них остаются. Отдельных рядов
  «Сейчас смотрят: новинки (…)» больше нет.
- «Ещё» открывает полный список той же коллекции, в котором только новинки, по всем её страницам.
- Непроверенные карточки остаются в ряду и в списке, приписки в заголовке нет; предупреждение в
  консоли остаётся.

## Capabilities

### Modified Capabilities

- `now-watching-new-releases`: ряды новинок заменяет фильтр штатных рядов; добавлен полный список
  новинок по «Ещё»; убрана приписка непроверенных в заголовке.
