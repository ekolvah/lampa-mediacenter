## ADDED Requirements

### Requirement: Трейлеры в KP-карточке
Карточка фильма или сериала из источника `KP` SHALL показывать кнопку «Трейлеры», когда
для её `imdb_id` в TMDB найден тайтл с видео. Список трейлеров SHALL совпадать с тем,
что показывает карточка того же тайтла из источника `tmdb`. Реакции SHALL подставляться
как раньше.

#### Scenario: Трейлер найден
- **WHEN** открыта KP-карточка с `imdb_id`, TMDB находит по нему фильм, и у фильма есть видео
- **THEN** в карточке есть кнопка «Трейлеры» со списком видео этого фильма в TMDB и реакции этого фильма

#### Scenario: Сериал
- **WHEN** TMDB находит по `imdb_id` сериал, а не фильм
- **THEN** видео и реакции запрашиваются для сериала с его TMDB id

#### Scenario: Нет imdb_id
- **WHEN** у KP-карточки нет `imdb_id`
- **THEN** карточка открывается без кнопки «Трейлеры», и запросов к TMDB нет

#### Scenario: TMDB не нашёл тайтл
- **WHEN** TMDB по `imdb_id` не возвращает ни фильма, ни сериала
- **THEN** карточка открывается без кнопки «Трейлеры»

### Requirement: Пустой ответ видео
Пустой ответ видео для найденного тайтла SHALL NOT мешать открытию карточки. Он MUST
быть виден в консоли.

#### Scenario: Видео не пришли
- **WHEN** TMDB нашёл тайтл, а запрос видео вернул пустой список (видео нет или запрос не удался)
- **THEN** карточка открывается с реакциями и без кнопки «Трейлеры», а в консоль пишется предупреждение с типом и id тайтла

### Requirement: Воспроизведение с пульта
Трейлер из KP-карточки SHALL запускаться с пульта плеером, выбранным в настройке
«Плеер для трейлеров».

#### Scenario: Запуск трейлера пультом
- **WHEN** на приставке в KP-карточке пультом нажата кнопка «Трейлеры» и выбран первый трейлер
- **THEN** открывается плеер, и YouTube-видео начинает играть
