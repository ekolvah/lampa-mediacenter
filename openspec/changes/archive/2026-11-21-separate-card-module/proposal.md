## Why

`plugins/kp-reactions-fix.js` — одно замыкание `patch()` с двумя ответственностями:

- **источник KP**: обёртки `KP.main` и `KP.list` (ряды «Сейчас смотрят», «Рекомендуем посмотреть»,
  «Ещё»), KP-история в рекомендациях ядра;
- **карточка**: реакции, русский трейлер, трейлер последнего сезона (`enrich` и всё под ним).
  Кнопки «Торренты»/«Трейлер» (`onFull`) уже вне `patch()`.

Возможности карточки достижимы только через обёртку `KP.full`, поэтому карточка другого источника
их не получает: «Бегущий по лезвию: Чёрный лотос» (`full:tmdb:84553`) показывает английский
трейлер, хотя сервис трейлеров находит русский дубляж (#94, #95, #96). Наблюдение на приставке
(2026-11-21, `tools/cdp.py`, записано в #93): в движке `Lampa.Api.full` — один диспетчер
`source(params).full(...)` для всех источников, экран карточки зовёт `Api.full(object, …)`.

Чтобы #94–#96 переносили код карточки, а не распутывали замыкание, сначала нужен рефакторинг без
изменения поведения.

**Отступление от issue #93:** issue предлагал два файла-плагина; пользователь выбрал «один файл,
два модуля» (почему — design.md, решение 1).

## What Changes

- В `plugins/kp-reactions-fix.js` выделяются общие помощники TMDB, модуль «Карточка» и модуль
  «Источник KP» (design.md, решение 1). Шапочный комментарий делится на абзацы двух модулей.
- Поведение не меняется, карточки других источников остаются как есть до #94.

## Standard approach

Официальной документации по плагинам Lampa нет (`docs/lampa-config-review.md`, раздел «Плагины»).
Поиск («Lampa plugin Lampa.Listener.follow('full')», «yumata lampa-source plugins Lampa.Api.sources
Listener full event») дал только исходники и плагины сообщества без руководства:
https://github.com/yumata/lampa-source, https://deepwiki.com/levende/lampa-plugins,
https://github.com/Zwanns/lampa-online, https://gist.github.com/dEN5-tech/4dae13913dff8a66ac20583c6317ad51
(плагин в IIFE со стартом по `Lampa.Listener.follow('app')` → `ready`, как у нас). Примера, где два
плагина делят помощников через глобальный объект, не нашлось. Опора — код живого движка (Why).
