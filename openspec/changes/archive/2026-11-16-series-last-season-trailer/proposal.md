## Why

У сериала «Джентльмены» кнопка «Трейлер» (и первый пункт «Смотреть» → «Трейлеры») играет трейлер
1-го сезона, хотя вышел 2-й (#64). Ожидается трейлер последнего вышедшего сезона, для всех сериалов.

**Воспроизведение, 2026-11-16.** Источник карточек на приставке — `KP` (`Lampa.Storage.field('source')`,
`cdp.py`). KP-карточка сериала — `KP_1435343` («Джентльмены» / «The Gentlemen», 2024, `tv`; поиск
`KP.discovery().search`). Её TMDB-тайтл — `tv/236235`. Ответы TMDB (`api.themoviedb.org/3`, ключ
`Lampa.TMDB.key()`):

- `tv/236235`: `number_of_seasons` = 3, `last_episode_to_air.season_number` = 2, `seasons` =
  `(1, 2024-03-07, 8 эп.)`, `(2, 2026-09-03, 8 эп.)`, `(3, air_date null, 0 эп.)`;
- `tv/236235/videos` (то, что берёт `tmdb.videos`): `ru Trailer 2024-02-26 «ДЖЕНТЛЬМЕНЫ Сезон 1 -
  Русский трейлер 2»`, `en Trailer 2024-02-22`, `en Clip 2024-03-07`. Ролика 2-го сезона нет;
- `tv/236235/season/2/videos`: `en Trailer 2026-08-24 «Season 2 Official Trailer»`,
  `en Teaser 2026-07-09`, `en Featurette 2024-08-14`.

`KP.full` для `KP_1435343` на приставке (`cdp.py`, Lampa на переднем плане): `movie.type` = `tv`,
`imdb_id` = `tt13210838`. В «Трейлерах» один ролик — `ru Trailer «Джентльмены (1 сезон) — Русский
трейлер #2 (4К, 2024)»`. Это ролик сервиса, а не TMDB.

**Причина 1: не тот тайтл.** `find/tt13210838` возвращает и `movie_results` = `[1823885 «The
gentlemen»]`, и `tv_results` = `[236235 «Джентльмены»]`. У `movie/1823885` нет даты выхода, runtime
и голосов, это пустая запись TMDB с тем же `imdb_id`, видео у неё 0. Плагин берёт `movie_results`
первым и не смотрит на тип карточки (`plugins/kp-reactions-fix.js:144-145`). Видео пустые, поэтому
плагин спрашивает сервис по названию и году 2024 без сезона и получает трейлер 1-го сезона. Реакции
тоже приходят от чужого тайтла.

**Причина 2: о сезоне никто не знает.** Если тайтл найден верно (`tv/236235`), картина та же. Плагин
спрашивает сервис, только когда в видео TMDB нет ни одного на `ru` (`plugins/kp-reactions-fix.js:66-67`),
а у сериала есть русский трейлер 1-го сезона. Движок ставит видео на `ru` раньше видео на `en`, а
внутри языка сортирует их по `published_at` по убыванию (наблюдение в архиве
`2026-11-16-trailer-button/proposal.md`). Поэтому первым снова идёт 1-й сезон.

**Зависимость готова.** `ekolvah/trailer-search` v0.2.0 (PR ekolvah/trailer-search#8, тег `v0.2.0`):
`FilmProfile.season` — необязательный `int ≥ 1`. Если ролика нужного сезона нет, библиотека отдаёт
лучший оставшийся, а `reason` заканчивается на `; season N fallback`
(`src/trailer_search/strategy.py:158` на теге). Структурного признака замены в `TrailerPick` нет.
Живая проверка в PR #8: `FilmProfile("Джентльмены", "The Gentlemen", 2024, season=2)` →
`3xow3-n2VQM`, «Джентльмены (2 сезон) - Русский трейлер (Дубляж, 2026) Гай Ричи».

**Решение пользователя, 2026-11-16.** Если русского трейлера последнего сезона нет, первым идёт
английский трейлер этого сезона из TMDB. Русские ролики старых сезонов остаются в списке после него.

## What Changes

- Если `find` по `imdb_id` вернул и фильм, и сериал, плагин берёт тот, чей тип совпадает с типом
  KP-карточки.
- Для KP-сериала, у которого последний вышедший сезон N ≥ 2, плагин берёт N из TMDB `tv/<id>`
  (`last_episode_to_air.season_number`). Сервис он спрашивает про трейлер сезона N всегда, даже если
  русское видео в TMDB есть.
- Ролик сервиса ставится первым. Если ролика нет, плагин берёт
  трейлер сезона N из TMDB `tv/<id>/season/N/videos` и ставит его первым, с
  предупреждением в консоли. Если нет и их, список остаётся как сейчас, тоже с предупреждением.
- Сервис принимает необязательный `season`. Если библиотека отдала ролик другого сезона, сервис
  отвечает «не найден» (`video_id: null`) и сохраняет причину. Ключ кэша учитывает `season`.
- Пин библиотеки в `tools/trailer-search.requirements.txt`: `v0.1.0` → `v0.2.0`.
- Фильмы и сериалы с одним вышедшим сезоном работают как раньше.

## Capabilities

### New Capabilities

- нет

### Modified Capabilities

- `kp-card-trailers`: новое требование «Трейлер последнего сезона». В «Русский трейлер с YouTube»
  добавляется исключение для сериалов с последним вышедшим сезоном N ≥ 2. В «Трейлеры в
  KP-карточке» — выбор между фильмом и сериалом из `find` по типу карточки.
- `trailer-search-service`: параметр `season` в «Поиск трейлера по названию», `season` в ключе
  «Кэш ответов».
