## Why

В «Избранном» один тайтл лежит двумя карточками, если его добавили из разных источников: пользователю
источник не важен, ему нужен один сериал в закладках.

**Воспроизведение** (приставка, 2026-11-23, `tools/cdp.py`, аккаунт с CUB-синхронизацией):
`Lampa.Favorite.get({type:'book'})` отдаёт две записи «Список смертников»:
`120911 | tmdb | imdb tt11743610 | 2022-06-30 | tv` и `KP_4396199 | KP | kinopoisk 4396199 | imdb tt11743610 | 2022-06-30 | tv`.
Падающий тест — `book list shows one card per imdb` (Group 1 в tasks.md).

**Причина** (живой код ядра, `Lampa.Favorite.check.toString()` на приставке):
закладка ищется только по `id` карточки — `Account.Bookmarks.find({ type: a, id: card.id })`;
`toggle` берёт тот же `cloud(card)`, `remove` шлёт `method: 'id'`. У карточки `kp_source` id вида
`KP_<kinopoisk_id>`, у `tmdb` — число TMDB, поэтому для ядра это разные тайтлы. Общий ключ у обеих
есть — `imdb_id`.

## What Changes

- Список закладок любого типа показывает тайтл один раз: записи с одинаковым `imdb_id` из разных
  источников схлопываются в одну.
- Карточка, чей тайтл уже в закладках карточкой другого источника, показывает метку закладки, а её
  кнопка закладки снимает все записи этого тайтла в выбранном списке, а не добавляет вторую.
- Сбой виден (spec, «Сбой схлопывания видно»).

## Capabilities

### New Capabilities

- `favorites-across-sources`: одна карточка тайтла в закладках независимо от источника.

### Modified Capabilities

Нет.

## Impact

Изменяются:

- `plugins/kp-reactions-fix.js` — раздел «Закладки»: обёртки `Lampa.Favorite.check`,
  `Lampa.Favorite.toggle`, `Lampa.Account.Bookmarks.get`; абзац в шапке.
- `tests/js/kp-reactions-fix.test.js` — двойники `Favorite`/`Account.Bookmarks`, тесты сценариев.
- `docs/lampa-config-review.md` — строка `kp-reactions-fix.js`: закладки и живая проверка.

Добавляются:

- `tests/live/favorites.sh`, `tests/live/favorites/one-card.js` — живая проверка (только чтение
  закладок, без правки аккаунта).

Удаляемых файлов нет. Зависимостей и сетевых запросов нет. Записи в аккаунте CUB не меняются:
схлопывание — только при чтении; существующий дубль уходит из аккаунта, когда пользователь снимает
закладку.
