## Context

Изменение `now-watching-new-releases` ставило за штатными рядами «Сейчас смотрят» свои ряды
новинок без «Ещё». По ревью пользователь решил иначе (proposal.md): фильтровать сами штатные ряды
и дать полный отфильтрованный список по «Ещё».

## Standard approach

Как Lampa на приставке строит «Ещё» и полный список. Наблюдение по `http://lampa.mx/app.min.js?v=1994464`,
снято через `cdp.py` 2026-11-18:

- `More.onVisible`: `var pages = this.data.total_pages || 1; if (pages <= 1) return;`. Кнопка
  «Ещё» есть только при `total_pages > 1`.
- `onmore` ряда: `Activity.push({url: data.url, title: data.title, component: 'category_full', page: 1,
  source: data.source || params.object.source})`. Полный список стартует с `page: 1` и зовёт
  `list` источника с тем же `url`.
- `category_full`:
  - `onBuild` вызывает `if (!data.results.length) return this.empty();`;
  - следующая страница грузится только при `this.object.page < this.total_pages`, затем идёт
    `this.object.page++`.
- Сама Lampa в своём `list` перескакивает пустую страницу: `if (data.results && !data.results.length
  && attempt < 5 && params.page && params.page < data.total_pages) { params.page++; list(...) }` с
  комментарием «берём следующую, иначе пагинация остановится».

Готового плагина, который фильтрует коллекцию Кинопоиска по году, не нашли: поиск по экосистеме
описан в design.md изменения `now-watching-new-releases`.

## Decisions

### 1. Фильтр штатного ряда на месте

Обёртка `KP.main` больше не вставляет свои ряды, а подменяет в первой порции штатный ряд
(по `url`, как раньше) его копией. В копии:

- `results` — новинки со страниц 1–5;
- `total_pages` — число страниц полного списка (решение 2);
- заголовок штатный, при недогрузке к нему добавляется « · неполный».

Остальные поля ряда, его место и «Ещё» не трогаются. Если новинок нет, ряда нет, в консоль идёт
предупреждение, как раньше.

### 2. Полный список: страница N = пачка страниц коллекции

Обёртка `KP.list` перехватывает запросы с `url` из `NEW_ROWS`. Остальные запросы уходят в
`kp_source` без изменений.

- Страница N полного списка собирается из страниц коллекции `5(N−1)+1 … 5N`. Используются те же
  сбор и фильтр, что для Главной.
- Страница 1 совпадает с рядом на Главной.
- `total_pages` = ⌈страниц коллекции / 5⌉ (сейчас 7).
- Число страниц коллекции берётся из её ответов: `total_pages` штатного ряда и любых страниц.
  Страницы за ним не запрашиваются.

**Почему пачками, а не 1:1.** Отфильтрованная страница 1:1 бывает пустой: на поздних страницах
встречается всего 2 новинки из 20. Пустую страницу `category_full` считает концом списка. Пачка из
5 страниц на замере никогда не бывает пустой. Если всё же пустая, обёртка делает то же, что Lampa:
`params.page++` и следующая пачка, пока не кончатся страницы.

Если не пришла ни одна страница пачки, вызывается `onerror` (экран ошибки Lampa). Если пришли не
все — список строится из пришедшего, в консоль идёт предупреждение. Срок ожидания пачки тот же,
`ROWS_TIMEOUT_MS`.

**Отвергнуто — отдельные ряды с особым `url`.** Это был прежний вариант с рядами рядом со
штатными. Он дублировал ряды на Главной и требовал разбирать служебный `url` в `KP.list`.

### 3. Непроверенные карточки — без приписки в заголовке

По решению пользователя приписки « · не проверено: N» в заголовке нет. Карточки остаются в ряду,
каждая даёт `console.warn` с названием и причиной (§IV: видно в консоли). Приписку « · неполный» не
трогаем: она означает сбой загрузки, а не свойство карточки.

## Risks / Trade-offs

| # | Риск | Чем закрыт | Проверка |
|---|---|---|---|
| R15 | Штатных «Сейчас смотрят» без фильтра больше не открыть | решение пользователя: старое не нужно | — |
| R16 | Полный список — до 5 запросов к КП на страницу и TMDB для старых сериалов | кэш `kp_source`/TMDB, пачка грузится только при прокрутке | живой шаг |
| R17 | Пустая пачка обрывает список | перескок как в Lampa (решение 2) | тест «empty batch skipped» |
| R9 | `kp_source` сменил `url` коллекций | нет штатного ряда → Noty, `KP.list` с другим `url` не перехватывается | тест «missing original row, noty» |
