# edit-secret-hook Specification

## Purpose
Ловит секреты устройства (токен аккаунта, почта/uid, пароль TorrServer) в файле сразу после того, как
агент его записал, в каком бы каталоге ни шла сессия, до коммита и push в публичный репозиторий.

## Requirements

### Requirement: Хук работает вне корня
PostToolUse-хук на `Edit|Write` из `.claude/settings.json` SHALL запускать проверку секретов при любом
текущем каталоге сессии, если `CLAUDE_PROJECT_DIR` указывает на корень проекта.

#### Scenario: Команда хука из чужого каталога
- **WHEN** команда хука выполняется в `bash` с cwd вне корня проекта, `CLAUDE_PROJECT_DIR` = корень, на stdin `{}`
- **THEN** она завершается с кодом 0 и без ошибки `No such file`

### Requirement: Путь файла от корня проекта
Хук SHALL определять путь записанного файла относительно корня проекта, а не текущего каталога: файлы
под `snapshots/` корня MUST пропускаться, а секрет в любом другом файле MUST давать код 2 при любом
cwd.

#### Scenario: Снапшот из подкаталога не блокируется
- **WHEN** хуку передан файл `snapshots/…` проекта с кредом, а cwd — подкаталог проекта
- **THEN** хук завершается с кодом 0

#### Scenario: Секрет из подкаталога ловится
- **WHEN** хуку передан файл вне `snapshots/` с кредом, а cwd — подкаталог проекта
- **THEN** хук завершается с кодом 2 и в stderr есть путь файла от корня и номер строки
