# kp-card-trailers Specification

## Purpose
Плагин `kp-reactions-fix.js` даёт карточкам источника `KP` трейлеры и реакции того же TMDB-тайтла, что у карточки источника `tmdb`, не подставляя чужой тайтл и не ломая открытие карточки.

## Requirements

### Requirement: Трейлеры в KP-карточке
Карточка фильма или сериала из источника `KP` SHALL показывать кнопку «Трейлеры», когда для неё
в TMDB найден тайтл с видео. Тайтл ищется по `imdb_id`. Если `imdb_id` нет или по нему TMDB
ничего не вернул, тайтл SHALL искаться по названию. Список трейлеров SHALL совпадать с тем,
что показывает карточка того же тайтла из источника `tmdb`. Реакции SHALL подставляться
для того же тайтла.

#### Scenario: Трейлер найден
- **WHEN** открыта KP-карточка с `imdb_id`, TMDB находит по нему фильм, и у фильма есть видео
- **THEN** в карточке есть кнопка «Трейлеры» со списком видео этого фильма в TMDB и реакции этого фильма

#### Scenario: Сериал
- **WHEN** TMDB находит по `imdb_id` сериал, а не фильм
- **THEN** видео и реакции запрашиваются для сериала с его TMDB id

#### Scenario: Нет imdb_id
- **WHEN** у KP-карточки нет `imdb_id`, а поиск по названию находит тайтл с видео
- **THEN** в карточке есть кнопка «Трейлеры» со списком видео найденного тайтла и его реакции, а запроса по `imdb_id` нет

#### Scenario: TMDB не нашёл тайтл
- **WHEN** TMDB по `imdb_id` не возвращает ни фильма, ни сериала, а поиск по названию находит тайтл
- **THEN** видео и реакции запрашиваются для тайтла, найденного по названию

### Requirement: Пустой ответ видео
Пустой ответ видео для найденного тайтла SHALL NOT мешать открытию карточки. Он MUST
быть виден в консоли.

#### Scenario: Видео не пришли
- **WHEN** TMDB нашёл тайтл, а запрос видео вернул пустой список (видео нет или запрос не удался)
- **THEN** карточка открывается с реакциями и без кнопки «Трейлеры», а в консоль пишется предупреждение с типом и id тайтла

### Requirement: Воспроизведение с пульта
Трейлер из KP-карточки SHALL запускаться с пульта плеером, выбранным в настройке
«Плеер для трейлеров».

#### Scenario: Запуск трейлера пультом
- **WHEN** на приставке в KP-карточке пультом нажата кнопка «Трейлеры» и выбран первый трейлер
- **THEN** открывается плеер, и YouTube-видео начинает играть

### Requirement: Поиск тайтла по названию
Поиск по названию SHALL идти по типу карточки: фильм ищется среди фильмов, сериал среди сериалов.
Результат подходит, если его русское или оригинальное название совпадает с русским или оригинальным
названием карточки. Названия сравниваются так же, как их сравнивает источник `KP`: без учёта
регистра, «ё» равно «е», знаки препинания не важны. Если у карточки есть год, поиск SHALL идти
только среди тайтлов этого года, и берётся первый подходящий результат. Если года нет, тайтл
SHALL приниматься, только когда подходящий результат один. Если тайтл не найден или поиск
не удался, карточка SHALL открываться без кнопки «Трейлеры». В консоль MUST писаться
предупреждение с названием карточки и годом, если он есть.

#### Scenario: Совпадение не первым результатом
- **WHEN** у KP-фильма «Лес» 2026 года нет `imdb_id`, а TMDB первым возвращает «Ведьмин лес», вторым «Лес»
- **THEN** видео и реакции запрашиваются для второго результата, «Лес»

#### Scenario: Совпадение по оригинальному названию
- **WHEN** у KP-фильма без `imdb_id` русское название не совпадает с русским названием результата TMDB, а оригинальные названия совпадают с точностью до регистра
- **THEN** тайтл найден, видео и реакции запрашиваются для него

#### Scenario: Сравнение без регистра, ё и пунктуации
- **WHEN** KP-фильм «Темный рыцарь» 2008 года без `imdb_id`, а TMDB возвращает «Тёмный рыцарь», или названия различаются только регистром и знаками препинания
- **THEN** результат считается совпадением

#### Scenario: Сериал ищется среди сериалов
- **WHEN** у KP-сериала нет `imdb_id`
- **THEN** поиск идёт среди сериалов, а видео и реакции запрашиваются как для сериала

#### Scenario: Нет года, совпадение одно
- **WHEN** у KP-сериала «Жизнь заново» нет ни `imdb_id`, ни года, а поиск без года находит один сериал с этим названием
- **THEN** видео и реакции запрашиваются для этого сериала

#### Scenario: Нет года, совпадений несколько
- **WHEN** у KP-фильма «Зверь» нет ни `imdb_id`, ни года, а поиск без года находит несколько фильмов «Зверь»
- **THEN** карточка открывается без кнопки «Трейлеры» и без запросов видео и реакций, а в консоль пишется предупреждение с названием

#### Scenario: Нет совпадения названия
- **WHEN** поиск вернул результаты, но ни у одного название не совпадает с названием карточки
- **THEN** карточка открывается без кнопки «Трейлеры» и без запросов видео и реакций, а в консоль пишется предупреждение с названием и годом

#### Scenario: Поиск не удался
- **WHEN** запрос поиска по названию завершился ошибкой
- **THEN** карточка открывается без кнопки «Трейлеры», а в консоль пишется предупреждение с названием и годом
