# card-season-badge Specification

## Purpose
Плагин `kp-reactions-fix.js` показывает на карточке сериала, сколько серий последнего вышедшего
сезона уже вышло и вышел ли сезон целиком, чтобы не открывать карточку ради этого.

## Requirements

### Requirement: Метка сезона
Видимая карточка сериала SHALL нести метку по сведениям TMDB о сериале. Сезон метки — сезон
последней вышедшей серии, «вышло» — её номер в сезоне, «всего» — число серий этого сезона по TMDB.
Сезон считается вышедшим целиком, когда «всего» больше нуля, «вышло» не меньше «всего» и следующая
объявленная серия не из этого сезона или её нет. Вышедший целиком сезон MUST показываться как
`S<сезон> ✓`, выходящий — как `S<сезон> <вышло>/<всего>`, а при неизвестном «всего» — как
`S<сезон> <вышло>`. Карточка фильма и карточка сериала без вышедших серий MUST оставаться без метки.

#### Scenario: Сезон выходит
- **WHEN** последняя вышедшая серия — 6-я 4-го сезона, в 4-м сезоне 10 серий, следующая серия — 7-я 4-го сезона
- **THEN** на карточке метка `S4 6/10`

#### Scenario: Сезон вышел целиком
- **WHEN** последняя вышедшая серия — 10-я 2-го сезона, во 2-м сезоне 10 серий, следующей серии нет
- **THEN** на карточке метка `S2 ✓`

#### Scenario: Объявлен следующий сезон
- **WHEN** последняя вышедшая серия — 8-я 1-го сезона, в 1-м сезоне 8 серий, следующая серия — 1-я 2-го сезона
- **THEN** на карточке метка `S1 ✓`

#### Scenario: Число серий сезона неизвестно
- **WHEN** последняя вышедшая серия — 2-я 3-го сезона, а число серий 3-го сезона по TMDB равно 0
- **THEN** на карточке метка `S3 2`

#### Scenario: Фильм
- **WHEN** видимая карточка — фильм
- **THEN** метки нет и сведения о сериале не запрашиваются

#### Scenario: Сериал без вышедших серий
- **WHEN** у сериала по TMDB нет последней вышедшей серии
- **THEN** метки нет

### Requirement: Любой экран и источник
Метка SHALL появляться на карточке сериала на любом экране, где Lampa рисует карточки (Главная,
«Избранное», категории, поиск), для источников `tmdb`, `cub` и `KP`. Карточка `KP` MUST считаться сериалом,
если её `type` — `tv`, а без `type` — если у неё есть `original_name`. Для карточки `KP` сериал MUST
определяться по `imdb_id`, а без него или без результата — по названию и году. Если TMDB-тайтл не
найден, на карточке MUST быть серая метка `S ?`, а в консоль MUST писаться `console.warn` с
названием.

#### Scenario: KP-карточка сериала
- **WHEN** видна карточка сериала источника `KP` (в «Избранном» или на Главной KP), чей TMDB-тайтл найден
- **THEN** на ней метка по сведениям этого тайтла

#### Scenario: KP-карточка сериала без type
- **WHEN** в «Избранном» видна карточка источника `KP` без `type`, с `original_name`, чей TMDB-тайтл найден среди сериалов
- **THEN** на ней метка по сведениям этого тайтла

#### Scenario: KP-карточка фильма без type
- **WHEN** видна карточка источника `KP` без `type` и без `original_name`
- **THEN** метки нет и запросов к TMDB нет

#### Scenario: Карточка tmdb или cub в «Избранном»
- **WHEN** в «Избранном» видна карточка сериала источника `tmdb` или `cub`
- **THEN** на ней метка по сведениям сериала с id карточки, без поиска тайтла

#### Scenario: TMDB-тайтл не найден
- **WHEN** для KP-карточки сериала TMDB-тайтл не найден
- **THEN** на карточке серая метка `S ?`, в консоли `console.warn` с названием

#### Scenario: Сбой поиска тайтла
- **WHEN** запрос поиска TMDB-тайтла для KP-карточки сериала завершился ошибкой
- **THEN** на карточке серая метка `S ?`, в консоли `console.warn`, и до перезапуска приложения поиск по этой карточке (источник + id) не повторяется

### Requirement: Запросы ограничены
Сведения для метки SHALL запрашиваться только для видимой карточки. За время работы приложения
поиск TMDB-тайтла (вместе с повтором без года) и запрос сведений о сериале MUST выполняться не больше одного раза на пару
«источник + id карточки», включая неудачные. Повторный показ карточки или другая карточка с тем же
источником и id MUST получать метку без нового запроса. Метка MUST NOT добавляться на карточку второй
раз.

#### Scenario: Повторный показ
- **WHEN** карточка сериала, уже получившая метку, снова становится видимой, или видна другая карточка с тем же источником и id
- **THEN** новых запросов к TMDB нет, на карточке одна метка

#### Scenario: Одновременные карточки одного сериала
- **WHEN** две карточки с одним источником и id становятся видимыми до ответа TMDB
- **THEN** уходит один запрос сведений о сериале, обе карточки получают метку

#### Scenario: Сбой запроса сведений
- **WHEN** запрос сведений о сериале завершился ошибкой
- **THEN** на карточке серая метка `S ?`, в консоли `console.warn` с id, и до перезапуска приложения запрос по этой карточке (источник + id) не повторяется

### Requirement: Сбой подключения виден
Если функции ядра, к которой подключается метка, нет, плагин SHALL показать `Lampa.Noty` и записать
`console.error` с её именем. Метки тогда нет, остальные функции плагина MUST работать.

#### Scenario: Нет хука карточки
- **WHEN** у ядра нет хука видимости карточки
- **THEN** на экране уведомление, в консоли ошибка с именем функции, Главная KP и закладки работают как без метки
