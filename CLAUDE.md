# Проект: домашний медиацентр (Samsung TV + Ugoos AM6)

Это не исходный код — рабочая директория для настройки и обслуживания домашнего
медиацентра: **Samsung QE55S95DATXXH (S95D, 55" QD-OLED)**, подключённая по HDMI
приставка **Ugoos AM6** (Android 9, Amlogic), на которой установлены
**TorrServe**, **VLC**, **Lampa**.

Цель: смотреть торрент-фильмы в 4K/HDR с этого TV бесплатно, с рабочим сетапом
(разрешение, глубина цвета, HDR, аудио passthrough).

## Правки конфигурации на устройстве — обязательный процесс

Эта директория — рабочая копия публичного репозитория
`github.com/ekolvah/lampa-mediacenter`. Работа только через PR: `main` защищён
правилом на стороне GitHub, прямой push и force-push в него отклоняются.
Мержит PR пользователь, не агент.

Перед ЛЮБОЙ правкой конфигурации на Ugoos/TV: снять снапшот по конвенции
[docs/snapshots-convention.md](docs/snapshots-convention.md), менять только одну вещь
за раз, подтвердить что работает, только потом следующее изменение. Снапшоты
не коммитятся — журналом служит `NOTES.md` внутри самого снапшота.

**Документы описывают текущее состояние, не историю.** Записи вида «что применено
такого-то числа», «поправка к предыдущей версии», описания удалённых плагинов —
в `docs/` не накапливаются: история изменений живёт в `snapshots/*/NOTES.md`
и в git. При правке дока старое состояние удалять, а не дописывать рядом.

**Сначала искать готовое решение, потом писать своё.** Экосистема Lampa большая,
типовые задачи уже закрыты чужими плагинами. Свой плагин — последний вариант:
его надо где-то хостить и поддерживать самому.

## Гейты качества

Перед коммитом — `py -3.12 scripts/ci_check.py` (весь набор; одна проверка —
`--only <имя>`). Этот скрипт и есть определение «зелёного»: и `.githooks/pre-commit`,
и правки агента идут через него. Подробности и обоснование каждой проверки —
[docs/quality-gates.md](docs/quality-gates.md).

Секреты: снапшоты содержат живой токен аккаунта и креды TorrServer, поэтому
`snapshots/` выведен из git через `.gitignore`, а гейт `remote` краснеет, если
оттуда что-то всё же попало в индекс. Репозиторий публичный: любой push
необратим и индексируется, отменить его удалением файла нельзя. В доках и
скриптах вместо настоящих значений писать заглушку (`token=<токен>`).

## Быстрый старт для агента

Приставка не всегда подключена по ADB — сначала уточни у пользователя,
включён ли Wireless debugging и актуален ли IP (`192.168.10.5` на момент
последней проверки, 2026-08-19), прежде чем пытаться `adb connect`.

TV отвечает на HTTP без всякой пары/подтверждения: `curl http://192.168.10.16:8001/api/v2/`
(IP на момент последней проверки, 2026-08-19) — этого обычно достаточно для
диагностики, глубже (Tizen SDB) не заходили.
