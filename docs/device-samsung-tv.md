# Телевизор: Samsung QE55S95DATXXH (S95D)

## Характеристики (сняты напрямую с TV через Smart TV API, 2026-08-19)

- Модель: **QE55S95DATXXH** — Samsung **S95D**, 55", QD-OLED, флагман 2024 года
- Разрешение панели: **3840×2160 (4K)**
- ОС: Tizen (Smart TV API version 2.0.25)
- Подключение: Wi-Fi (networkType: wireless)
- IP на момент проверки: `192.168.10.16`
- Developer Mode: выключен (`developerMode: 0`)

По официальным данным линейки S95D — **Dolby Vision не поддерживается**
(принципиальная позиция Samsung: ставка на HDR10+ вместо DV). Это совпадает с
тем, что независимо показала сама приставка Ugoos AM6 при опросе EDID TV —
см. [4k-hdr-setup.md](4k-hdr-setup.md). Поддерживается **HDR10 и HDR10+**.

## Как подключиться (лёгкая диагностика, без Developer Mode)

Samsung Smart TV API отдаёт информацию об устройстве по HTTP без какой-либо
пары/подтверждения на самом TV:

```bash
curl -s http://192.168.10.16:8001/api/v2/
```

Возвращает JSON с моделью, разрешением, версией ОС, поддерживаемыми функциями
пульта (`remote_available`, `remote_touchPad`, `remote_voiceControl`) и т.д.

## Более глубокий доступ (не проверялось, требует доп. шагов)

Для отправки команд (переключение входа, управление, чтение списка приложений)
нужна WebSocket-пара по `ws://192.168.10.16:8001/api/v2/channels/samsung.remote.control`
с подтверждением PIN-кода на экране TV при первом подключении — токен потом
можно переиспользовать. Для полноценного shell-доступа (аналог adb) нужен
**Tizen SDB**: включить Developer Mode в приложении «Apps» на TV (ввести `12345`
на пульте), указать IP компьютера, установить `sdb` из Tizen Studio SDK.
Пока не делали — переходить на этот уровень только если лёгкой диагностики
через `/api/v2/` окажется недостаточно.
